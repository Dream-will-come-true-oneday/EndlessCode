# 命令实时建议面板 Spec

> 增量需求：基于已交付的斜杠命令系统（docs/command-system），升级补全体验。

## 背景

当前命令补全需主动按 Tab，多匹配时只在聊天区输出一行候选文本，无描述、无法键盘选择，与主流终端 Agent（Claude Code）「输入前缀即时弹出建议、↑↓ 选择、Enter 执行」的体验不一致。

## 目标

- 输入 `/` 前缀时实时弹出建议面板，所见即所选。
- 键盘全流程可用：↑↓ 选择、Enter 执行、Esc 关闭，手不离开键盘。
- 现有 Tab 补全与既有交互零回归。

## 功能需求

- **F1: 实时过滤建议。** 空闲状态下输入以 `/` 开头且不含参数时，输入框上方显示建议面板：候选为名称或别名前缀匹配的可见命令（按名称排序），每行展示命令名、别名与一句话描述；无匹配或输入非命令文本时面板隐藏。
- **F2: 键盘操作。** 面板可见时：↑↓ 循环移动高亮；Enter 立即执行高亮命令（走既有命令分发，不产生 AI 请求），清空输入并关闭面板；Esc 关闭面板并保留已输入文本；继续输入时面板实时刷新。Tab 补全行为保持不变。
- **F3: 别名参与匹配。** 别名前缀同样命中建议，选中后执行其规范命令。
- **F4: 隐藏命令隔离。** 隐藏命令不出现在建议面板中。

## 非功能需求

- **N1: 焦点稳定。** 面板出现、刷新、关闭全程不夺走输入焦点，光标位置保持。
- **N2: 零回归。** 现有全部测试通过；会话恢复搜索、审批按键、Shift+Tab 模式切换行为不变。
- **N3: 高度受限。** 面板最多显示约 8 行，超出可滚动。

## 不做的事

- 不做参数级建议、模糊（非前缀）匹配、鼠标点击选择。
- 不做建议面板的持久化配置或自定义排序。

## 验收标准

- **AC1:**（F1）输入 `/mem` 出现含 `/memory` 与 `/mem` 及描述的面板；输入普通文本面板消失。
- **AC2:**（F2）面板中 ↑↓ 循环移动高亮；按 Enter 后对应命令被执行（如 `/status` 输出状态文本且无 AI 请求），输入被清空、面板关闭。
- **AC3:**（F2）Esc 关闭面板且输入保留；恢复输入时面板重新出现并实时过滤。
- **AC4:**（N2）Tab 补全行为与现状一致；会话恢复与审批态键盘行为不变（现有测试全部通过）。
- **AC5:**（F3、F4）别名前缀命中规范命令；隐藏命令不出现在建议中。
