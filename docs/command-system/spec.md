# 斜杠命令系统 Spec

## 背景

Endless Code 的终端客户端目前只有 7 个硬编码斜杠命令（退出、计划/执行模式切换、上下文压缩、会话恢复、权限审计）。它们以静态字典形式写死在界面层，命令与处理方法一一绑定到具体界面类的私有方法，导致：

- 无法携带命令元数据（描述、用法、参数提示），用户只能靠帮助文本猜命令；
- 不支持别名、不支持带参数命令、不支持 Tab 补全；
- 命令实现直接依赖终端渲染框架的内部状态，无法脱离界面单独测试；
- 每新增一个高频操作都要侵入界面主类，扩展成本随命令数量线性增长。

本次改造将斜杠命令重构为一套集中式、可测试、可扩展的命令系统，并补齐一批高频内置命令。

## 目标

- 所有命令通过集中式注册中心统一管理，注册即获得元数据、别名与冲突检测。
- 命令实现与终端渲染框架解耦：命令只面向抽象的界面控制接口编程。
- 用户获得一致的命令体验：大小写不敏感、别名、参数、Tab 补全、帮助与错误引导。
- 内置覆盖日常高频操作的命令集，包括需要 AI 参与处理的预设提示词命令。

## 功能需求

### 命令框架

- **F1: 集中式注册中心。** 每条命令携带元数据：名称、别名、描述、用法说明、类型、参数提示、处理逻辑。注册时校验名称与别名唯一，冲突时立即报错并指明冲突方。支持标记命令为隐藏（不出现在帮助与补全中）。
- **F2: 命令解析。** 以 `/` 开头的输入视为命令；第一个空格之前为命令名，之后整体作为参数字符串；命令名大小写不敏感；仅输入 `/` 或命令名为空视为非法命令输入。
- **F3: 三类执行模式。** 命令按执行方式分为三类：
  - 纯本地命令：只读或本地状态操作，立即返回结果；
  - 界面状态命令：会改变界面状态或触发异步流程（如压缩、恢复会话）；
  - AI 提示词命令：把预设提示词（可拼接用户参数）送入对话流，由 AI 处理。
- **F4: 界面控制抽象层。** 命令通过一层抽象接口操作界面：显示系统消息、显示错误、发送用户消息进入对话流、查询与切换权限模式、查询 token 用量与会话信息、刷新状态栏、结束程序等。命令实现不直接依赖任何具体渲染框架。
- **F5: 输入分流。** 用户提交输入的入口先判断是否为命令：是命令则本地分发执行并消费输入，不送入 AI；不是命令才进入原有对话流程。命令分发期间的异常不得导致界面崩溃。
- **F6: 别名与 Tab 补全。** 命令名与别名均可直接执行。在输入框按 Tab：前缀唯一匹配时直接补全命令名；多个匹配时弹出候选列表供选择；隐藏命令不参与补全与帮助展示。
- **F7: 状态栏与未知命令引导。** 状态栏持续显示当前权限模式与高频命令提示；输入未知命令时统一提示并引导到帮助命令。

### 内置命令

- **F8: 内置命令集。** 提供以下命令（含必要别名）：

| 命令 | 类型 | 行为 |
|---|---|---|
| 帮助 | 本地 | 列出全部可见命令与简介；带参数时显示单个命令的详细用法 |
| 退出 | 本地 | 安全退出程序（保留现有两个别名） |
| 上下文压缩 | 界面 | 手动触发上下文压缩（保留现有行为） |
| 清空对话 | 界面 | 清空当前会话（内存对话与当前会话持久化记录），回到全新会话状态，操作前给出确认提示 |
| 模式切换 | 界面 | 进入计划模式 / 退出计划模式开始执行（保留现有行为） |
| 会话恢复 | 界面 | 进入会话恢复选择流程（保留现有行为） |
| 权限审计 | 本地 | 显示当前会话最近的权限审计事件（保留现有行为） |
| 记忆管理 | 本地 | 显示当前长期记忆概况（项目级与用户级索引内容摘要） |
| 权限管理 | 界面 | 不带参数显示当前权限模式与可选模式；带参数切换到指定权限模式 |
| 综合状态 | 本地 | 一次性显示版本、provider、模型、权限模式、token 用量、会话标识与消息数 |
| 代码审查 | AI | 将预设的代码审查提示词送入对话流，引导 AI 审查当前改动 |
| 修复错误 | AI | 将最近一轮的错误或失败结果连同预设提示词送入对话流，引导 AI 分析修复 |
| 解释上下文 | AI | 将最近一次 AI 回复或工具调用结果连同预设提示词送入对话流，引导 AI 解释 |

## 非功能需求

- **N1: 可测试性。** 命令注册、解析、分发与全部内置命令逻辑可脱离终端渲染框架进行纯单元测试。
- **N2: 兼容性。** 现有 7 个命令的名称与行为保持不变，现有界面测试全部通过。
- **N3: 健壮性。** 单个命令执行失败只产生错误提示，不影响后续输入与对话。
- **N4: 安全性。** 命令输出沿用现有脱敏机制，不在界面显示 API key 等敏感信息。

## 不做的事

- 不做用户自定义命令、插件机制或命令配置文件。
- 不做命令串联、管道或多行命令脚本。
- 不做参数级 Tab 补全（只补全命令名与别名）。
- 不做命令执行历史（上下方向键翻命令）。
- 不为隐藏命令提供任何用户可见入口。

## 验收标准

- **AC1:**（F1）重复注册同名或同别名的命令时，注册动作立即失败并报告冲突；帮助输出包含每条可见命令的名称、别名、描述与用法。
- **AC2:**（F2）`/STATUS 详细信息` 与 `/status 详细信息` 行为一致；`/status` 后的文本完整作为参数传入；仅输入 `/` 时提示非法输入而不送入 AI。
- **AC3:**（F3）三类命令各至少有一条内置命令可端到端执行成功；AI 类命令执行时对话流中出现预设提示词构成的用户消息且 AI 正常响应。
- **AC4:**（F4、N1）全部内置命令逻辑的单元测试不启动任何渲染框架即可通过。
- **AC5:**（F5、N2）普通文本输入照常送入 AI；命令输入不产生 AI 请求；现有 7 个命令行为与改造前一致，原有界面测试全部通过。
- **AC6:**（F6）Tab 补全：唯一前缀直接补全，多匹配弹出候选列表，隐藏命令不出现在候选与帮助中。
- **AC7:**（F7）状态栏显示当前权限模式与高频命令提示；输入不存在的命令时提示未知并引导帮助命令。
- **AC8:**（F8）清空对话需要确认后才生效，生效后内存对话与当前会话持久化记录被重置；权限管理带参数可切换模式且非法模式名给出提示；记忆管理、综合状态、权限审计输出与当前实际状态一致。
- **AC9:**（N3）构造一个执行中抛异常的命令，界面仅显示错误提示，之后仍可正常输入与对话。
