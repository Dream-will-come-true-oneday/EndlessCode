# 会话内模型切换与输出样式 Spec

> 增量需求：基于已交付的斜杠命令系统（docs/command-system、docs/command-suggest）与两层上下文压缩能力，补齐运行期模型切换与回答风格控制。

## 背景

当前模型在启动时一次性选定：配置多个 provider 时进入选择态由用户挑一个，配置单个时直接启用，此后整个会话无法更换。用户想在同一轮工作中「用便宜模型跑调查、换强模型写实现」只能重启程序，且重启会丢失当前上下文。

回答风格同样固定：系统提示里的语气与输出要求写死，用户无法让回答更简洁或更详细，也没有主流终端 Agent 那样的输出样式（output style）概念。

此外，不同模型的上下文窗口不同，而窗口大小直接决定自动压缩的触发阈值；现有实现只在启动时按所选模型计算一次，运行期换模型必然带来阈值失效问题，需要一并定义行为。

## 目标

- 会话内切换模型，且当前对话上下文、权限模式与会话身份保持不变。
- 用内置预设样式调整回答的详略与讲解程度，切换后下一轮生效。
- 切换结果全程可见：状态栏、状态命令与会话存档都能反映当前模型与样式。
- 新命令可发现：出现在命令帮助与实时建议面板中。
- 现有交互、压缩、记忆、权限与审计零回归。

## 功能需求

- **F1: 模型清单与切换。** 空闲态执行模型切换命令：不带参数时列出全部已配置且可用的模型（编号、名称、模型标识，并标记当前使用项）；带编号或名称参数时切换到目标模型。切换后当前对话历史、权限模式、会话标识与已显示的聊天内容全部保留。
- **F2: 切换失败原子性。** 目标模型不可用（密钥缺失、密钥解析失败或客户端构造异常）时，保持原模型与当前对话完全不变，并给出可读的失败原因；失败后可以继续正常对话。
- **F3: 切换后一致性。** 切换后对话请求、上下文压缩与长期记忆更新一致使用新模型；上下文占用按新模型的窗口重新估算，不沿用旧模型的用量基准；当新窗口更小导致已有上下文超限时，走既有自动压缩路径而不是直接请求失败。
- **F4: 忙碌保护。** 一轮任务进行中（等待模型输出、工具执行、审批等待，或处于会话恢复/检查点回滚的选择态）时拒绝切换模型与样式，提示稍后重试，且不产生任何状态变更。
- **F5: 输出样式预设。** 提供一组命名的内置样式，至少覆盖：默认、简洁、讲解、教学四种取向，区别在于回答的详略程度与是否附带原理和权衡说明。样式切换命令不带参数时显示当前样式、全部可选样式及各自一句话说明；带样式名参数时切换；样式名未知时报错并列出可选值，当前样式保持不变。样式只影响回答风格，不改变可用工具集、权限判定、权限模式与压缩策略。
- **F6: 样式生效时机与稳定性。** 样式切换自下一轮请求起生效，不改写已产生的历史消息，也不改变消息数量；同一样式在同一会话内持续有效期间，系统提示保持稳定不变，避免反复打破提示缓存。
- **F7: 状态可见与可追溯。** 状态栏与状态命令均显示当前模型、当前输出样式与生效的上下文窗口；模型切换与样式切换在会话存档中留下可追溯记录，会话恢复列表展示该会话最近使用的模型而非最初使用的模型。
- **F8: 命令可发现。** 两个新命令出现在命令帮助列表中，参与输入前缀的实时建议与补全，命令说明清晰表达用途与参数。

## 非功能需求

- **N1: 零回归。** 现有全部测试通过；启动期模型选择、权限模式切换（含快捷键）、审批按键、会话恢复与检查点回滚行为不变。
- **N2: 切换无副作用。** 切换模型不新建会话目录、不清空历史与审计记录、不重置权限规则；切换过程无可感知卡顿。
- **N3: 缓存友好。** 模型与样式切换均为显式低频操作，切换完成后系统提示在同一会话内保持稳定，保留提示缓存收益。
- **N4: 安全一致。** 切换不绕过任何权限层；切换到新模型后，危险命令拦截、越界路径拦截与人在回路审批行为与原模型一致；失败原因提示与会话存档记录均不泄露密钥。

## 不做的事

- 不做用户自定义样式文件与样式模板编辑（如需，另立子项目）。
- 不做跨模型自动 fallback、按任务类型自动选模型或负载均衡（属重试/路由子项目）。
- 不做模型能力探测与历史消息的跨协议格式转换（当前会话历史仅含纯文本与工具调用，无需转换）。
- 不把模型与样式选择持久化到配置文件；重启后回到配置默认值。
- 不做样式或模型切换的键盘快捷键。
- 不做 LLM 请求失败的重试与指数退避（已选定方案，另立子项目 A 推进）。

## 验收标准

- **AC1:**（F1）配置两个模型时，空闲态执行模型切换命令且不带参数，输出列出两项并标记当前项；指定切换到另一项后，状态栏的模型标识随之变化，此前聊天内容仍在界面上，状态命令显示的消息数不归零。
- **AC2:**（F2）将目标模型的密钥环境变量置空后执行切换，界面给出可读失败原因，状态栏仍显示原模型，随后的对话正常完成且消息数继续累加。
- **AC3:**（F3）切换到上下文窗口更小的模型后继续对话，上下文超过新窗口阈值时出现既有的自动压缩提示而不是请求失败，压缩后对话可继续推进。
- **AC4:**（F4）在一轮任务进行中（模型输出或审批等待期间）执行切换命令，得到「任务进行中」类提示；本轮结束后状态命令显示模型与样式均未变化。
- **AC5:**（F5）样式命令不带参数时列出全部预设与当前样式；切换到「简洁」后下一轮回答明显更短且不含额外原理说明；传入不存在的样式名时报错并列出可选值，当前样式不变。
- **AC6:**（F6）切换到「讲解」样式后，历史消息数量与已显示内容不变，新一轮回答附带原理或权衡说明。
- **AC7:**（F7）状态命令输出同时包含当前模型、输出样式与上下文窗口三项；切换模型后检查会话存档能看到切换记录，会话恢复列表显示的是最近使用的模型。
- **AC8:**（F5、N4）切换到任一其它模型后，触发一次危险命令与一次项目外路径写入，两者仍被拦截且提示与原模型一致；审批流程仍正常弹出。
- **AC9:**（F8、N1）输入两个新命令的前缀时建议面板出现对应候选；命令帮助列出两条新命令；现有测试全部通过，启动期模型选择与权限模式快捷键行为不变。
